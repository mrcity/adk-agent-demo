# ADK Agent Demo

In this demo, you will create a barista agent at a coffee shop to answer questions about coffee and other products they sell. The agent is implemented using Gemini, Google ADK (Agent Development Kit), Streamlabs, and some GCP resources, including Cloud Run and Firebase Firestore Vector DB.

## Working with the demo

Look through the numbered `.md` files in order, from 1 through 8. You can clone this repo right into GCP Cloud Shell, or copy and paste the contents directly.
